## Bring Your Own Data and Keys

DEHA ONE processes data but does not own it. Your business data lives on your own infrastructure.

**BYOD (Bring Your Own Data)**
- Connect databases, REST APIs, cloud storage, and files (CSV, Excel, JSON, Parquet) and webhooks
- Results sink back to your own databases and storage, the platform keeps only the operational layer
- Route to your own vector store and your own archive
- Snapshot versioning with time-travel and rollback

**BYOK (Bring Your Own Keys)**
- Bring your own AI provider credentials, including self-hosted models
- Embeddings, completions, and tools run on your accounts
- Tool credentials (OAuth2, API keys, signed webhooks) are vaulted and never logged

## Multi-user, multi-model, always live

| Dimension | How it works |
|---|---|
| **Workspaces** | Hard isolation across every layer: data, knowledge, credentials, lineage, billing, and logs. Cross-workspace access is structurally impossible. |
| **Models** | Pick a model per agent or per call. Use simple aliases (`fast`, `smart`, `cheap`, `reasoning`) and the platform routes, with cross-provider fallback. |
| **Versions** | Run multiple versions of an agent at once with weighted traffic. Returning users stay on the same variant. |
| **Always live** | Every change deploys with zero downtime. Agents, automations, schedules, and channels reconfigure live. |
| **Channels** | One agent serves every channel with the same context, knowledge, and tools, wherever the customer messaged from. |

## Built-in trust

| Concern | How DEHA ONE handles it |
|---|---|
| Unauthorized access | Single sign-on, per-user and per-entity API keys, IP allow-lists |
| Credential leaks | Encrypted vault, secure vault references, never logged |
| Runaway costs | Per-user credit limits, alert thresholds, overage actions (alert / throttle / block), rate limits |
| Bad agent output | Automatic quality scoring, optional human review gates, full audit log |
| Data leakage between users | Full per-workspace isolation enforced at every layer |
| Lost messages | Reliable delivery with automatic retries, failure recovery, and rollback |
| AI hallucination | Cited answers from your knowledge and data map, semantic reranking, and review gates |
