This guide walks you through creating your account, building your first AI agent with DEHA, giving it your data, and testing it live.

<Steps>
  <Step title="Sign in to the dashboard">
    Head to [app.deha.one](https://app.deha.one) and create your account. You can sign up with your email address, Google, or single sign-on (SSO).

    <Info>
      New accounts include a free trial with starter credits so you can explore every capability -- agents, automations, data, knowledge base, optimization -- before choosing a plan.
    </Info>

    Once you are signed in, you will land on the dashboard -- your central hub for managing agents, automations, data, and integrations.
  </Step>

  <Step title="Create your first agent with DEHA">
    The fastest way to create an agent is to ask DEHA, your built-in AI assistant.

    1. Click the **DEHA** button in the dashboard sidebar
    2. Describe the agent you want to create in plain language. For example:

    > "Create a customer support agent that answers questions about our products, looks up orders in our database, greets users warmly, and escalates billing issues to a human."

    3. DEHA designs the agent (its flow, tools, and knowledge), builds the setup, validates it, and shows you a preview with a clear summary of changes
    4. Review the details and click **Deploy**. DEHA also runs smoke tests and self-heals if anything fails on first run.

    Your agent is now live.

    <Tip>
      You can also build agents in the **Agents** page using the visual editor, or fine-tune them directly in the built-in editor with diff and version history. See [Creating Agents](/agents/creating-agents).
    </Tip>
  </Step>

  <Step title="Give your agent data and knowledge">
    To make your agent dramatically more useful, give it data and documents to work with.

    - **Data sources**: Connect a PostgreSQL, MySQL, MongoDB, REST API, file, or webhook in the **Data Studio**. Your agent can now answer questions about your data in plain English.
    - **Living data map**: Let [İDRAK](/idrak/overview) map everything you've connected into one picture, so your agent can ask questions across all of it -- with cited answers.
    - **Knowledge base**: Upload PDFs, documents, spreadsheets, or paste URLs in the **Knowledge** page. Your agent searches them and answers with citations.
    - **Tools**: Hook up REST APIs or run sandboxed Python code via the **Integrations** page.

    DEHA can do all of this for you -- just say "connect my PostgreSQL database and let the agent answer questions about orders."
  </Step>

  <Step title="Test your agent">
    Send a test message and watch your agent respond. **Web Chat** is the fastest way -- it works instantly, with no setup.

    - **Web Chat**: Click the chat widget on the dashboard to start a conversation
    - **API**: Call the agent directly from your application (see [API Reference](/api-reference/gateway-agent-invoke))

    If the response is not quite right, go back to DEHA and refine your agent. You can say things like:

    > "Update my support agent to also handle return requests, check order status from the database, and route refund requests to a human review queue."

    DEHA updates the setup, redeploys, and runs regression tests -- automatically.
  </Step>

  <Step title="(Optional) Reach customers on more channels">
    When you're ready to go beyond Web Chat, connect the messaging platforms your customers already use.

    1. Go to **Channels** in the sidebar
    2. Choose a channel: **WhatsApp**, **Telegram**, **Email**, or **Slack**
    3. Follow the on-screen setup to link your account
    4. Assign your agent to handle messages on the channel

    The same agent handles every channel with the same context and knowledge. See [Channels](/channels/overview).
  </Step>

  <Step title="Monitor usage and quality">
    Keep track of activity, credit consumption, and response quality from the dashboard.

    1. Navigate to **Billing** to see credit balance, usage breakdown by agent and operation, and quota status
    2. Open **Logs** to view activity and any active alerts
    3. Use the **Review Queue** to approve any agent responses flagged for human review

    <Tip>
      Set up quota alerts and overage actions (alert / throttle / block) so usage never surprises you. See [Credits & Quotas](/billing/credits-and-quotas).
    </Tip>
  </Step>
</Steps>
