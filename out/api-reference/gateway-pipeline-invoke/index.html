      Invoke Pipeline
      curl --request POST \
  --url https://api.example.com/api/v1/agent/{user_id}/pipeline/{pipeline_name}/invoke \
  --header 'Content-Type: application/json' \
  --data '
{

      {
  "reply": "<string>",
  "session_id": "<string>",
  "trace_id": "<string>",
  "pipeline_name": "<string>",
  "model": "<string>"
}
      Invokes a named pipeline and returns the result synchronously. Pipelines orchestrate multi-step workflows that can include data processing, multiple agent calls, transformations, and integrations. The request has a 65-second timeout. For pipelines that may take longer, consider breaking them into smaller steps or using asynchronous patterns.

      ​
      Authentication

      Requires an API key in the Authorization header with the Bearer prefix. The key’s user must match the URL {user_id}.

      ​
      Path Parameters

      ​
      user_id
      string
      required
      Your user identifier.
      ​
      pipeline_name
      string
      required
      The name of the pipeline to invoke (as defined in your pipeline configuration).

      ​
      Request Body

      ​
      message
      string
      required
      The input message or trigger for the pipeline.
      ​
      session_id
      string
      Optional session identifier. Auto-generated if omitted.
      ​
      context
      object
      Optional key-value context passed to the pipeline. Available to all steps during execution.

      ​
      Response

      ​
      reply
      string
      The pipeline’s output text.
      ​
      session_id
      string
      The session identifier used for this execution.
      ​
      trace_id
      string
      Trace identifier for debugging and support inquiries.
      ​
      pipeline_name
      string
      The name of the pipeline that was executed.
      ​
      model
      string
      The LLM model used (if applicable).

      ​
      Error Responses

      StatusDescription
      401Invalid or missing API key
      403API key user does not match URL user
      404Pipeline not found
      429Rate limit exceeded
